# CVPR 2026 stage matrix

| Stage | Required focus | Manual or unresolved boundary |
|---|---|---|
| `anonymous_submission` | US Letter shell, `review` mode, anonymous review artifact/PDF metadata | eight-content-page boundary, visible/link anonymity, live portal |
| `supplementary_package` | anonymous optional supporting material | reviewers need not inspect it; core evidence remains in main paper |
| `rebuttal` | `rebuttal` mode and one total PDF page | content cannot be moved to external links; current portal controls |
| `camera_ready` | no review/rebuttal option and current official package | camera-ready kit, CRF state, disclosures, receipt |

The Compute Reporting Form is a portal/form check. It is required with the supplement
but does not determine acceptance.
