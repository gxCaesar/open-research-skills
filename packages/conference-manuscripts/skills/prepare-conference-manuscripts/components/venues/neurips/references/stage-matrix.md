# NeurIPS 2026 stage matrix

| Stage | Required focus | Manual or unresolved boundary |
|---|---|---|
| `anonymous_submission` | anonymous/default-or-`main` style, checklist, 50 MB limit | nine-content-page boundary, checklist truth, COI/profile and portal state |
| `supplementary_package` | anonymous supporting material | reviewers need not read it; visible anonymity remains manual |
| `openreview_discussion` | discussion tied to original submission and existing evidence | no revised-paper or supplement upload is authorized |
| `camera_ready` | `[main,final]`, checklist, funding/competing-interest disclosure | ten-content-page boundary, lay summary, final portal receipt |
