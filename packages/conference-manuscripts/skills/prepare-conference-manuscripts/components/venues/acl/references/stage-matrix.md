# ACL 2026 stage matrix

| Stage | Required focus | Manual or unresolved boundary |
|---|---|---|
| `anonymous_submission` | ARR review source, A4/`11pt`, `review` option, anonymity, acknowledgments absent, Limitations | body/reference/appendix boundary and actual rendered anonymity |
| `arr_author_response` | concise discussion tied to reviewer concerns and existing evidence | it is not a replacement-paper upload; live length and portal controls |
| `venue_commitment` | ARR-to-venue commitment, author and artifact consistency | eligibility, deadlines, forms, and portal receipt |
| `camera_ready` | final ACL invocation, Limitations, restored identities only where permitted | 9/5 content limits, publication package, and final upload receipt |

The Responsible NLP checklist is a portal/form requirement, not a PDF-heading test.
