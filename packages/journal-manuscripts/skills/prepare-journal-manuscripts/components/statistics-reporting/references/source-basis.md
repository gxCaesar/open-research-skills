# Source basis

Checked on 2026-09-04. The target venue, supplied protocol, and applicable reporting
guideline remain authoritative.

| Source | Use |
|---|---|
| Nature Portfolio reporting standards: <https://www.nature.com/nature-portfolio/editorial-policies/reporting-standards> | current reporting-summary and reproducibility expectations for applicable Nature Portfolio papers |
| Nature Methods collection, Statistics for Biologists: <https://www.nature.com/collections/qghhqm> | practical background on design, replication, uncertainty, error bars, multiplicity, interactions, nesting, regression, and related issues |
| EQUATOR Network: <https://www.equator-network.org/> | locate the current study-type reporting guideline; it is an index, not a substitute for opening the selected guideline |
| CONSORT/SPIRIT: <https://www.consort-spirit.org/> | current randomized-trial and protocol reporting resources when the study type applies |

Nature does not prescribe one universal test for every design. Use these sources to
support transparent reporting, then choose or audit the method from the actual design,
estimand, assumptions, and field standard. Open current journal instructions and the
selected study-type guideline before calling any item a hard requirement.
