# Scientific design template library

These original editable templates demonstrate visual relationships, not a mandatory
house style or journal acceptance standard. Select by the scientific job. Inspect a
render before adapting the native objects; copying only the text defeats their purpose.

## Image-concept reconstruction example

The [editable cell-response example](../assets/design-templates/cell-response-native.pptx)
and [preview](../assets/design-templates/cell-response-native.png) show an original
image-generated concept reconstructed into separate native text, shapes and connectors.
Reuse the relationship between input state, a conditioned model and predicted output;
replace all scientific content from the new project's sources. The network, cell
silhouettes, profile tiles and shading are illustrative, not data or a published model.

The single-slide canvas is 180 × 105 mm, an authoring choice rather than a journal rule.
The PPTX contains no embedded picture. Label and node edits survived a native-format
save/reopen, and LibreOffice rendered the original and edited copies. Microsoft
PowerPoint GUI editing was not verified. The image tool did not expose its backend
model identity, so this example does not certify a particular GPT Image version.
It remains AI-derived conceptual design; check the destination's disclosure and image
policy before adapting it for publication.

## Inspected paper precedents

Primary figures and captions inspected on 2026-09-09. These are design observations,
not current venue rules. No paper artwork is included in the templates.

- **Object transformation and auxiliary input.** Li et al., diaTracer, *Nature
  Communications* 16, 95 (2025), Fig. 1, PDF p. 3.
  [Original figure source](https://www.nature.com/articles/s41467-024-55448-8).
  The main transformation occupies the upper band; a conditional DDA input joins a
  separate downstream route. See [panel design lessons](nature-panel-design-lessons.md)
  for the source-specific interpretation. The reusable idea is visual emphasis and
  branch placement, not the software chain or its FDR threshold.
- **Architecture versus training/inference.** Abramson et al., AlphaFold 3, *Nature*
  630, 493–500 (2024), Fig. 2, PDF p. 3.
  [Original figure source](https://www.nature.com/articles/s41586-024-07487-w).
  Representation arrays, module flow and training branches retain distinct roles;
  measured training curves remain separate. Adapt that separation, not its molecule
  drawings, block counts, diffusion process or stopped-gradient behavior. Fig. 1 is
  a structure/performance overview, not this architecture reference.
- **Matched route comparison.** Rafailov et al., DPO, NeurIPS 2023, Fig. 1, PDF p. 2.
  [Original figure source](https://proceedings.neurips.cc/paper_files/paper/2023/file/a85b405ed65c6477a4fe8302b5e06ce7-Paper-Conference.pdf).
  Matched preference inputs expose a removed intermediate training stage. See
  [conference figure design](conference-figure-design.md) for its claim boundary.
  Apply the alignment principle only when the new comparison has a matched contract.

The worked example's science comes from Schneider et al., *Generative Intervention
Models for Causal Perturbation Modeling*, ICML 2025, §§3–4, Equations (3)–(6) and
Figure 1 ([paper](https://proceedings.mlr.press/v267/schneider25a.html)). Its visual
composition is an original image-concept-to-native reconstruction, not copied paper art.

## When reusing

Read the source first, select a fitting template, then recompose around the current
scientific object. Change geometry when the new labels or mechanism need more room.
Keep the short upper labels, informative graphics and necessary lower notation where
they help. Do not impose equations, panels, optional branches or comparison claims
merely because a template has space for them.
