`develop-method-to-sota` 用于「pilot 已经跑通、但还打不过基线」的那一段。
它不是调参助手：它先要求您量出这个任务上还剩多少可赢的余量、以及您自己代码上的噪声底，
再决定值不值得设计组件、以及该从哪一层开始改。

本地 [SKILL.md](../skills/develop-method-to-sota/SKILL.md) 是运行入口，本页说明作者
如何准备输入、发起任务、审阅输出。

## 安装与首次调用

按[仓库快速开始](../README.md#快速开始)安装完整 `skills/develop-method-to-sota` 目录，
并在所用 agent runtime 中刷新技能列表。

```bash
SKILL_DIR="$PWD/skills/develop-method-to-sota"
```

首次请求直接围绕真实实验：

```text
使用 $develop-method-to-sota。当前 dev split 上我的方法比基线低 1.8 个点，
已经试过三组超参。请先做 headroom-measure，再决定要不要设计组件。
```

## 先量再造

两个数必须在设计任何组件之前存在，而且都要**实测**：

- **headroom** —— 这个任务、这个表示下还剩多少分可拿。它是「任务 × 表示」的函数，
  不是任务的属性，所以要逐任务量、不许从相邻任务外推。
- **噪声底** —— 同代码同 split，只换种子 / 库版本 / 机器时的波动。
  **bootstrap 标准误不是噪声底**：它描述的是一次运行内部的重采样，不是流水线重跑。

写成 `mean ± k×range` 的阈值要先折算成标准差再用；n=4 时 `2×range` 约等于 5 个 sd，
比它看起来的要弱得多。能配对就配对，不要拿两个点估计加一个拍脑袋的余量当比较。

headroom 若已落到噪声底以内，这个任务在当前表示下就是饱和的 —— 那是三条退出里的第一条。

## 按层读误差

一个聚合数说不出方法在哪里输。设计组件之前先切分评测集，逐层读误差，并且
**每层都要报进入的样本数和被排除的样本数**。没有分母的层无法与任何东西比较。

看三种形状：承载了大部分总损失的层（组件在这里才可能回本）、已经接近 oracle 臂的层
（这里投入零回报）、以及比平凡预测还差的层（那是缺陷，不是研究机会）。

## 一次一个组件

每次迭代开跑前写下四行：**Order**（配方 / 目标对齐 / 数据 / 集成 / 测试时计算 / 架构，
架构最后）、**construction shape**（这个候选操作什么对象、对它做什么，一句话，不带产品名）、
**机制假设**、**预期生效的那一层**。

对照臂必须**摧毁机制并保留其余一切**。后半句才是实际会被违反的那半句：一个仍然施加了
另一个真实干预的对照会拿回大半涨幅，把本来成立的组件判死。
**不许用单种子的对照下 void 判决** —— 击杀是不可逆的那一侧。

同 construction shape 的候选继承前一次的击杀，除非能一句话说清哪处计算变了。改名不算。

## 三条合法退出

停下来必须点名是哪一条：① 实测 headroom ≤ 实测噪声底；② 预登记预算耗尽 —— 这一条把决定
交回给人，不是让您自行冻结；③ 唯一通过对照的组件被别人抢发 —— 这一条回到 charter。

「试了很多个都失败」不是退出。宣称饱和之前，**oracle 臂必须真跑过**
（给模型一个部署时永远拿不到的输入），否则「没有方法有用」和「本来就没东西可找」无法区分。

## 校验迭代账本

随包带了一份可跑的干净账本和一份已知坏的账本。先看合格的样子:

```bash
python3 "$SKILL_DIR/scripts/check_iteration_ledger.py" \
  "$SKILL_DIR/examples/iteration-ledger/clean.json"
```

再看它会挡住什么 —— 单种子的 void 判决、重复了已被击杀的 construction shape、
以及没有实测支撑的饱和退出:

```bash
python3 "$SKILL_DIR/scripts/check_iteration_ledger.py" \
  "$SKILL_DIR/examples/iteration-ledger/known-bad.json"
```

**shape 的比较只去掉大小写、标点和空白**,所以它抓得住改名,抓不住换一种说法。
语义层面的去重仍然是您的判断,校验器只强制"您已经注意到的重复必须被写下来"。

## 交付与验收

一轮结束交出：实测 headroom、实测噪声底、迭代次数、被击杀的 construction shape 及其理由、
以及下一步会冻结的那一个配置。缺这些字段的循环，别人无法采信，只能重跑。
