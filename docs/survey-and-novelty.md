`survey-and-audit-novelty` 把一个方向变成一个**决定**：调研以判词收尾而不是以文献列表收尾，
新颖性审计的任务是**摧毁**这个想法而不是确认它新，可行性检查问的是这个想法需要的变量
是否真的共存于同一批拿得到的样本里。

本地 [SKILL.md](../skills/survey-and-audit-novelty/SKILL.md) 是运行入口。

## 先声明贡献车道

车道在检索**开跑之前**写下来，因为它决定什么才算撞车。写在后面，判词就会跟着检索
碰巧返回的东西走。

| 车道 | 主张什么 | 撞车怎么起作用 |
|---|---|---|
| `discovery` | 发现了关于世界的一个具体事实 | 二元且脆：同一发现被先发 = 归零 |
| `sota-method` | 方法在某个任务上更好 | 分级且稳：同任务别人只是对比项，只有同等幅度才致命 |
| `benchmark` | 覆盖了一个被点名的评测空白 | 看覆盖：只有填的是同一个空白才算 |

`discovery` 与 `benchmark` 是并列车道，不是方法没赢时的安慰奖，各自有必填字段
（discovery 要写 falsifier，benchmark 要写空白名和现有套件为何不覆盖）。

**「这片地全被发表过了」是关于车道的陈述，不是关于空间的陈述。**

## 联合随机变量审计

问题不是「每个变量是否在某处可得」，而是「它们是否被观测在同一批、你拿得到的样本上」。
证据是一张**实测共存计数表**，在写任何分析代码之前产出。「数据都在」不是那张表。

**共存为零关闭的是一个数据源，不是一个方向。** 接下来有三步，跳过它们直接宣告
「数据不存在」就是把数据问题讲成了没有证据的断言：换 / 扩数据源；放宽匹配层级到更粗
但仍有意义的单位（通路、复合物、机制类）；或者自己汇编这个配对并说明汇编方式与失败率。

## 多角度检索

一种提法只返回一个邻域。跑 6–8 个独立框架，**并且把返回为空的那些也记下来** ——
读者无法从记录里区分「没查」和「查了是空」。

至少安排一遍**以抢发为目标**的对抗检索。确认性检索和抢发式检索找到的是不同的论文，
只有后者算证据。判断候选撞车要读它的方法部分，不是摘要。

各处置状态的计数之和必须等于检查过的候选总数。**分母不闭合就是藏了一次静默驳回。**

## 撞车判定与击杀层

三个判词分开记录，合并会藏住到底是哪一个在起作用：

- `scoop_verdict`：`IDENTICAL` / `ADJACENT` / `UNCERTAIN` —— **只有 IDENTICAL 杀**，
  相邻工作是可以在其上构造创新点的基线。
- `feasibility`：由实测 headroom 与实测噪声底支撑。
- `venue_fit`：可以建议停，但**必须挂自己的名字**。把 venue-fit 的疑虑伪装成撞车判决，
  等于一次不可申诉的静默驳回。

击杀必须点名死在哪一层：**提法**（换提法即可，资产没死，这一层最常被误报成资产死亡）、
**数据**（要过枚举关，第一个地方没有不算）、**任务**（实测 headroom ≤ 实测噪声底）。
**只有任务层杀资产。**

报一批击杀之前先对自己的击杀跑一次 repair table：逐个问「哪一处可得的修正会翻转它」。
大部分都能翻转，说明这次审计量的是你的疲劳而不是文献。把这个比例连同击杀一起报出来。

## 校验调研账本

```bash
python3 "$SKILL_DIR/scripts/check_survey_ledger.py" \
  "$SKILL_DIR/examples/survey-ledger/clean.json"
```

汇总行会把**分解量印在总数旁边**(`adjacent=1 identical=1 irrelevant=1 uncertain=1`
对着 `scanned=4`),分母闭没闭合一眼可见。已知坏的那份演示它挡什么:

```bash
python3 "$SKILL_DIR/scripts/check_survey_ledger.py" \
  "$SKILL_DIR/examples/survey-ledger/known-bad.json"
```

它不判断新颖性,只强制三件事:分母闭合、击杀点名层级、`venue_fit` 与 `scoop_verdict` 分开记。

## 交付与验收

交出：车道、共存计数表、检索角度清单（含空结果）、候选处置账（分母闭合）、
三个分开的判词、击杀的层级、以及 repair table 的比例。
