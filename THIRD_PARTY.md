# Third-party boundary

This repository does not vendor third-party papers, venue templates, fonts, images, datasets,
model weights, or source code. Small JSON, Markdown, and code fixtures in the tests are original
synthetic examples.

Some skill modes use separately installed Python packages or system commands. Dependency files
identify the versions exercised by this repository; those projects are not redistributed here and
remain subject to their own licences. Users must separately verify the redistribution terms of any
material they add to outputs produced with these skills.
