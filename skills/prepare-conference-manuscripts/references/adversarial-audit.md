# Adversarial conference audit

Run independent audit lenses against the exact candidate artifacts. Seek the strongest
plausible falsifier, not confirmation.

## Scientific contract

Check that the question, task, data, split, independent unit, comparator, metric,
selection rule, uncertainty, result, and conclusion remain identical across abstract,
main text, figures, tables, appendix, supplement, and released materials. Trace each
load-bearing claim to its producer. Test leakage, recipe parity, negative results, and
whether a simple fair alternative closes the claimed gain.

## Statistics and evaluation

Check the actual independent unit, exclusions, missingness, aggregation, seed role,
uncertainty, multiplicity, stopping, and model-selection boundary. Repeated runs do not
create new biological or subject-level samples. A statistically non-significant result
does not establish equivalence.

## Novelty and related work

Identify the closest technically relevant work and compare the exact contribution,
task, protocol, evidence, and claimed margin. Use current primary sources where novelty
is load-bearing. Adjacent work requires a delta analysis; it is not automatically an
identical contribution.

## Claims and readability

Find unsupported generalization, causal language without identification, abstract or
conclusion drift, hidden limitations, ambiguous denominators, and citation scope that
does not support the sentence. Then check paragraph jobs, definition order, notation,
and consistency. Do not use stylistic polish to conceal a scientific defect.

## Artifact execution and compliance

Run the package's deterministic TeX, PDF, archive, and report checks where applicable.
Inspect the rendered candidate manually. Confirm anonymity, template version, page
structure, disclosure, supplement boundaries, archive safety, and agreement between
documented commands and supplied artifacts.

For every finding, record `observed`, `inferred`, `not_run`, or `failed`; priority;
location; impact; smallest valid action; and the check that would settle it. A critical
finding must rest on an official hard rule or directly observed scientific defect, not
inference alone.
