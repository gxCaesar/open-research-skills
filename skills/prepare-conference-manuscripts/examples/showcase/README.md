# Conference showcase: a source defect and a claim repair

This small teaching example shows the difference between an automated source check
and scientific editing. It is not an accepted paper, a real experiment, official venue
policy or a complete submission template.

![Six constructed task scores.](preview.png)

## Read the example

| File | Purpose |
|---|---|
| [before.tex](before.tex) | Deliberately flawed source: an identity command, an acknowledgment block and an overbroad result sentence |
| [after.tex](after.tex) | Revision retaining the same constructed observations while repairing those issues |
| [scores.csv](scores.csv) | Six paired synthetic task scores; every point comes from one row |
| [figure.json](figure.json) | Reproducible source-data plot specification |
| [demo-profile.json](demo-profile.json) | Teaching-only source rules, defined below |
| [preview.png](preview.png) | Curated preview generated by the bundled renderer |

The profile's `SHOWCASE_README` source ID refers to this document. For this fictitious
anonymous stage only, the contract requires the `article` class, `graphicx` package
and an abstract; it flags active `author`/`affiliation` commands and acknowledgment
sections. The profile's date records this teaching fixture, not a live policy refresh.
Use a current official adapter for real submissions.

## Before and after

**Before:** “The candidate consistently outperforms the baseline across all tasks.”

**After:** “In six illustrative tasks, the candidate score is higher on four tasks and
lower on two. The mean paired difference is 0.005 arbitrary score units.”

The source has paired differences of 0.02, 0.01, -0.01, 0.02, 0.01 and -0.02.
There is no fitted model, uncertainty estimate or inference about a real benchmark.
The revised sentence retains the two unfavorable tasks. The checker does not discover
or validate this scientific edit; inspecting the source data is essential.

**Figure legend.** Each point is one constructed task. The horizontal axis is its
baseline score and the vertical axis its candidate score, both in arbitrary units.
All six rows are displayed; no summary, fit, error bar or statistical test is shown.
This is a measured-value plotting demonstration, not a schematic-image example.

## Run from an installed copy

Set `SKILL_DIR` to the directory containing the installed `SKILL.md`. Set `DEMO_OUT`
to a fresh directory outside the skill. Python dependencies must already be available.

```bash
DEMO="$SKILL_DIR/examples/showcase"
MPLCONFIGDIR="$DEMO_OUT/.mpl" XDG_CACHE_HOME="$DEMO_OUT/.cache" \
  python3 "$SKILL_DIR/scripts/render_evidence_figure.py" \
  "$DEMO/figure.json" "$DEMO_OUT/figure"

python3 "$SKILL_DIR/components/manuscript-core/scripts/audit_tex.py" \
  "$DEMO/before.tex" --profile "$DEMO/demo-profile.json" \
  --stage anonymous_submission --format markdown

python3 "$SKILL_DIR/components/manuscript-core/scripts/audit_tex.py" \
  "$DEMO/after.tex" --profile "$DEMO/demo-profile.json" \
  --stage anonymous_submission --format markdown
```

Run the intentional-failure command separately if the shell stops on nonzero exits.

| Check | Expected observation |
|---|---|
| Plot renderer | Exit 0; `figure.svg`, `figure.pdf`, `figure.png` |
| `before.tex` | Exit 1; `ANON_SOURCE_IDENTITY` at line 3 and `ANON_ACKNOWLEDGMENTS` at line 12 |
| `after.tex` | Exit 0; zero source findings |

The source audit cannot establish rendered anonymity, page limits, statistical validity
or submission readiness. This demo does not compile the TeX, contact a venue, use an
image-generation service or demonstrate the separate concept-to-native-PPTX workflow.
Only the small PNG preview is curated here; local outputs need not be published.
