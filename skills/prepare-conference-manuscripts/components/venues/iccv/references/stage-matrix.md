# ICCV 2025 stage matrix

| Stage | Required focus | Manual or unresolved boundary |
|---|---|---|
| `anonymous_submission` | US Letter shell, `review` mode, anonymous source and PDF metadata | eight-content-page boundary, visible and link anonymity, live portal state |
| `supplementary_package` | anonymous optional supporting material | reviewers are encouraged but not obliged to look; no numeric size cap is stated |
| `rebuttal` | `rebuttal` mode | no page count is stated on ICCV's pages; the CVPR one-page limit is not inherited |
| `camera_ready` | no review or rebuttal option, page numbers off | current camera-ready package and portal receipt |

Non-compliance is decided before review rather than by a reviewer: a submission that is
not properly anonymized, does not use the template, or exceeds eight pages excluding
references is rejected without review.

Page numbering flips between stages. The review version carries page numbers and the
camera-ready version must not show any, which the style package handles through its
mode option rather than through a manual setting.
