# ICLR 2027 stage matrix

| Stage | Required focus | Do not infer |
|---|---|---|
| `abstract_registration` | genuine informative abstract; complete author set and current profiles | that a placeholder can be repaired later or a new author can be added |
| `anonymous_submission` | current style, double blindness, nine main-text pages, references then appendix, AI-use statement | that source anonymity proves rendered or supplement anonymity |
| `supplementary_package` | anonymous appendix/code/data and main/supplement consistency | that reviewers will inspect supplementary material |
| `discussion_revision` | concern-to-evidence map, clearly communicated changes, ten main-text pages | that every upload will be read or a different central paper is acceptable |
| `camera_ready` | current final instructions, ten main-text pages, final-copy mode, truthful AI statement | that advance guidance establishes the live upload fields |

External OpenReview writes are never implied by local readiness.
