# AAAI-27 stage matrix

| Stage | Required focus | Do not infer |
|---|---|---|
| `abstract_registration` | complete title and genuine abstract; consistency with the planned paper | an unofficial word range or later edit permission |
| `anonymous_submission` | current submission style, double blindness, seven content pages, nine total pages, references-only pages 8--9, no acknowledgments | that a source-only check proves rendered anonymity or page boundaries |
| `supplementary_package` | anonymous technical, multimedia, or code/data material; critical evidence remains in main paper | that reviewers will inspect the supplement |
| `author_feedback` | answer each material concern with existing evidence; preserve claim and protocol boundaries | permission for new experiments, length, or revised uploads beyond current instructions |
| `camera_ready` | current publication instructions, authors and acknowledgments restored as allowed, source package and presentation obligations | submission-era rules still apply unchanged |

The OpenReview form is external and time-varying. Treat its current fields, file limits,
and enabled actions as `UNVERIFIED` until directly observed by an authorized author.
