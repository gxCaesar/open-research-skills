# Repositories, citation, and metadata

## Repository decision

1. Use a data-type-mandated repository when applicable.
2. Otherwise prefer a community-recognized discipline repository.
3. If none fits, use a durable generalist or institutional repository with persistent
   identifiers and public metadata.
4. Do not use a lab website, personal drive, temporary cloud link, or code-hosting branch
   as the only archival data route.

Examples of repository classes include sequencing archives, structural databases,
proteomics or metabolomics repositories, neuroimaging archives, controlled human-data
repositories, earth-science data centres, social-science archives, and generalist
repositories. Verify the current data-type and journal mandate rather than choosing from
an undated list.

## Landing-page record

A reusable record normally needs a persistent identifier, title, creators, repository,
publication year, resource type, description, version, licence/rights, file list,
variables and units, provenance, processing, relations to manuscript/code/protocol, and
clear access conditions. DataCite version-specific fields should follow the current
schema and the selected repository's interface.

Dataset citations commonly contain creator, year, dataset title, repository/publisher,
version when meaningful, and persistent identifier. Follow the target journal's style
and include supporting public datasets in the reference list where required.

## README and file organization

For each deposited file state its name, contents, format, role, related figure/table,
variables, units, allowed values, missing-value codes, transformations, and required
software. Separate raw and processed data. Use descriptive names. Map each central
result from sample/experiment/run through raw input and processed file to its exact
display or table.

Record exclusions and anomalies that change claim-bearing data, including observed
issue, affected units, disposition, and scientific impact. Use repository-managed
version and integrity metadata where available. Do not copy private execution records or
agent workflow material into the public deposit.

## FAIR review

- **Findable:** persistent identifier, rich searchable metadata, and identifier in the
  metadata.
- **Accessible:** standard resolution protocol, explicit authentication/authorization,
  and metadata that remain discoverable when data are restricted.
- **Interoperable:** community formats, vocabularies, units, identifiers, and qualified
  relations.
- **Reusable:** licence, provenance, methods, variables, quality notes, version, and
  community-standard metadata.

Before final wording, test each link outside the author account as appropriate, open the
files, compare the repository record with the manuscript, and verify the authors have the
right to apply the stated licence.
