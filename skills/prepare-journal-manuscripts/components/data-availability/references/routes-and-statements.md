# Access routes and statement patterns

Replace every bracketed field with a verified fact. Delete inapplicable sentences.

## Public repository

Required facts: data scope, repository, persistent identifier, version where relevant,
licence, exact contents, and dataset citation.

```text
The [raw/processed/source] data supporting [claims or displays] are available in
[repository] under [persistent identifier]. The deposited record contains [contents and
version].
```

## Controlled access

Required facts: why open sharing is not possible, public metadata, repository/record,
controller, eligible requesters, application route, approval or agreement conditions.

```text
The [data] are not publicly available because [specific legal, ethical, consent, privacy,
or security reason]. A metadata record is available at [identifier]. Qualified
researchers may apply through [durable route]; requests are reviewed by [controller]
and require [conditions].
```

## Within paper or supplement

Use only when every supporting file is genuinely article-hosted and small enough. Name
the exact Source Data, Supplementary Data, or table files. Do not write “all data are in
the paper” when raw or figure source data are missing.

## Reused public data

Name the original dataset, repository, identifier, release/version or access date when
needed, and formal citation. Distinguish reused data from data generated in the study.

## Third-party restricted data

Name the owner/provider, licence or other restriction, why authors cannot redistribute,
the permission route, and any derived or aggregate data that authors may share. Do not
promise access that only the owner can authorize.

## Justified request

Use only when no suitable repository route is possible. Name the specific reason,
responsible institutional group, eligible purpose/users, contact route, review
conditions, and available metadata or representative data. A personal email alone is
not a durable route.

## Not applicable

State why no data were generated or analysed. This route fits genuinely theoretical or
commentary work, not an empirical study with unlisted inputs.

## Embargo

An embargo modifies a repository route; it is not a future-upload promise. Record the
existing repository and identifier, release date or event, reviewer route, and repository
support for the embargo. Verify current journal permission.
