# Chinese author alignment

Translate access logic, not vague wording.

| 中文 | Preferred English | Check |
|---|---|---|
| 数据可用性声明 | Data Availability | use the journal heading |
| 原始数据 | raw data | do not use for processed tables |
| 处理后数据 | processed data | state processing/code route |
| 源数据 | source data | map to exact figures or tables |
| 补充材料 | Supplementary Information | name exact files |
| 登录号 | accession number | copy the assigned identifier exactly |
| 永久链接 | persistent URL | prefer repository identifier/DOI when available |
| 受限数据 | restricted data | explain reason, controller, route, and conditions |
| 脱敏数据 | de-identified data | do not call anonymous without evidence |
| 合理请求 | reasonable request | insufficient without durable procedure |
| 数据使用协议 | data-use agreement | state when actually required |

Common conversions:

- “所有数据见补充材料” becomes an exact list of Source Data or Supplementary Data
  files; flag missing raw data.
- “可向通讯作者合理索取” requires the restriction reason, responsible institution,
  eligible users, conditions, and durable contact route.
- “因隐私不能公开” requires consent/legal basis, public metadata, access controller,
  application route, and agreement or approval conditions.
- “接收后上传” is not current availability. Deposit before submission or record a
  concrete repository action and reviewer route.
- “使用公开数据库” requires the database, identifier, version/release or access date,
  and dataset citation.

When useful, return English submission text followed by a separate `中文核对` list. Do
not insert Chinese explanatory notes into an English manuscript unless the journal asks
for bilingual text.
