# Assigning the lenses

Five reviewers reading for everything produce five copies of the same review, weighted
toward whatever the abstract emphasised. Assign one lens each and keep the reports apart
until adjudication.

## The five lenses

**Claim support.** Take each claim in the abstract and the conclusion, find the evidence
offered for it, and judge whether that evidence carries that claim. Report claims that
are broader than their support, and support that no claim uses.

**Method correctness.** Ask whether the described procedure could produce the reported
numbers at all. Check the split, the leakage surface, the unit of independence, the
metric definition, and the direction of every comparison.

**Comparison fairness.** Ask whether the comparators were given a real chance: tuned on
the same budget, run on the same data, reported with the same uncertainty. A comparator
that was reimplemented rather than run deserves an explicit note.

**Reproducibility.** Work only from the released material. This lens executes rather than
reads; see the artifact-execution reference.

**Significance.** Assume every number is correct and ask who changes what they do. This
is the lens that catches a correct paper with no consequence.

## Model families

Run the lenses across more than one model family where that is available. Families fail
differently, and the places where two families disagree about the same section are the
places where the writing is genuinely ambiguous rather than merely disliked.

Record which family produced which report. An adjudication that cannot attribute a
finding cannot weigh it.

## Report format

Each reviewer returns findings, not prose. A finding names the location, states what is
wrong, and says what would have to change. Ratings without located findings are not
usable, and a summary recommendation with no finding beneath it should be dropped at
adjudication.
