# Advanced native method diagrams

Two original educational figures show different ways to organize a dense scientific
schematic. Each provides a one-slide native PPTX, editable SVG and vector PDF.
Labels, biological silhouettes, tokens, module shapes and connectors remain separate
objects. Neither PPTX contains an embedded picture.

## Nature-inspired spatial mechanism

![Spatial context, matched profiles and donor-level comparison](nature-spatial-mechanism.png)

[Native PPTX](nature-spatial-mechanism.pptx) ·
[Vector PDF](nature-spatial-mechanism.pdf) ·
[Editable SVG](nature-spatial-mechanism.svg)

The upper panel follows a selected tissue region into a cell, paired molecular
profiles and within-donor matching. The lower panels separate the conditioned
response model from the independent comparison unit. Open space, organic biological
outlines and aligned sampling relationships organize the reading path.

The tissue and cell geometry are schematic. Matrix tiles, donor identifiers and
cell counts are examples, not measurements. Panel c explains cells nested within
donors; it deliberately shows no invented effect sizes or confidence intervals.

## Conference-inspired conditioned architecture

![Conditioning streams, two interaction blocks and expanded residual computation](conference-conditioning-architecture.png)

[Native PPTX](conference-conditioning-architecture.pptx) ·
[Vector PDF](conference-conditioning-architecture.pdf) ·
[Editable SVG](conference-conditioning-architecture.svg)

The main panel separates baseline state, perturbation and context inputs. Both
interaction blocks receive both conditioning streams. An expanded block shows
state queries, shared condition keys/values, attention mixing, two residual
additions and a feed-forward transformation. Observed response enters the
training-only loss, not the inference input.

This is a defined fictional teaching architecture, not a reported model. Token
counts and shading do not specify tensor dimensions, attention weights or measured
performance. Solid lines indicate computation; dashed lines distinguish
conditioning, prediction, training-only use and the labelled block-detail leader.
The connectors and labels, not their colours alone, identify the routes.

## Edit and reuse

Open a PPTX and select text or individual objects, or open the SVG in a vector editor.
Keep the physical page size and inspect the result at its intended manuscript width.
If you move a module, check its complete route and attachment points. Some long
routes use separately editable segments; automatic rerouting of whole modules is
not claimed. Adapt the actual operations and sampling relationship to your study,
not just the visible names.

The canvases are 183 mm wide, with Arial text and near-8 pt panel letters. These are
design examples, not official templates or a blanket submission-compliance claim.
The [Nature figure guide](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)
informed physical sizing, editable text and content-driven panel hierarchy; each
journal or conference still needs its own current requirements.

The design references were AI-generated and then reconstructed as native objects.
No generated bitmap is embedded in the delivered diagrams. The image tool did not
expose its backend model identity, so this example does not certify a particular
GPT Image version. Native export, save/reopen and rendered inspection were checked.
Microsoft PowerPoint GUI editing and journal permission for AI-assisted figures
are not asserted. Check the target venue's current image policy before manuscript use.

The files are editable examples, not a general architecture generator. For a fully
runnable source-data figure, use the adjacent
[spatial multiomics atlas](../spatial-multiomics-atlas/README.md).
